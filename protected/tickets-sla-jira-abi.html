W (thời gian phản hồi/xử lý) = mốc SLA − Created. P1, P2, S1 tính theo giờ đồng hồ 24/7. P3, P4, S2, S3 chỉ tính phút nằm trong giờ hành chính 8x5 (Thứ 2–6, 08:00–17:30) — thời gian ngoài giờ/cuối tuần không tính vào W.

Bộ lọc & tính SLA

Chọn 1 trong 2 cách bên dưới — kết quả nạp vào đều chạy chung 1 pipeline tính SLA/hiển thị bảng biểu ở dưới.
Cách 1 — Lấy trực tiếp từ Jira (cần API token)
Cần biến môi trường JIRA_BASE_URL/JIRA_EMAIL/JIRA_API_TOKEN đã cấu hình trên server. Nếu tài khoản của bạn không tự tạo được API token (bị chặn cấp tổ chức), dùng Cách 2 bên dưới.
Cách 2 — Import file Excel/CSV export từ Jira
Vào queue 425 trên Jira (hoặc Issue Navigator, JQL project = HQ) → thêm cột Priority, Created, và 2 cột SLA Time to first response, Time to resolution (nếu queue có sẵn) → Export → CSV/Excel. Tool sẽ tự nhận diện tên cột (không phân biệt hoa/thường, gần đúng là được).
Chưa import file nào.
