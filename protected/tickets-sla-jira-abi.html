Bộ lọc & tính SLA

Chọn 1 trong 2 cách bên dưới — kết quả nạp vào đều chạy chung 1 pipeline tính SLA/hiển thị bảng biểu ở dưới.
Cách 1 — Lấy trực tiếp từ Jira (cần API token)
Cần biến môi trường JIRA_BASE_URL/JIRA_EMAIL/JIRA_API_TOKEN đã cấu hình trên server. Nếu tài khoản của bạn không tự tạo được API token (bị chặn cấp tổ chức), dùng Cách 2 bên dưới.
Cách 2 — Import file Excel/CSV export từ Jira
Vào queue 425 trên Jira (hoặc Issue Navigator, JQL project = HQ) → thêm cột Priority, Created, và 2 cột SLA Time to first response, Time to resolution (nếu queue có sẵn) → Export → CSV/Excel. Tool sẽ tự nhận diện tên cột (không phân biệt hoa/thường, gần đúng là được).

Báo cáo SLA hàng tháng
Các chỉ số Total Received, Total Done, Still Open, Avg First Response (h), First Response SLA Met %, Avg Resolution (h), Resolution SLA Met % — tool tự tính trực tiếp từ Jira (Cách 1 bên dưới), không cần chờ khách hàng gửi báo cáo cuối tháng nữa. Import file / nhập tay chỉ để đối chiếu hoặc bổ sung các tháng cũ không còn kéo được từ Jira.
Cách 1 — Tính trực tiếp từ Jira (khuyến nghị)
Lấy toàn bộ issue project HQ có Created trong tháng chọn, loại ticket status Cancel, rồi tính: Total Received = số issue tạo trong tháng · Total Done = issue đã ở status nhóm "Done" (Resolved/Closed...) · Still Open = Received − Done · Avg (h)/SLA Met % của First Response & Resolution = tính trên các issue đã có chu kỳ SLA hoàn tất (đã phản hồi/đã xử lý xong — khớp đúng cách khách hàng tự tính, không tính issue đang chạy dở).
