Tính Lợi Nhuận Crs

Upload file PAKD dự án (khung mẫu HQSOFT) + file Detail Timesheet Report xuất từ ERP → tự động tính chi phí nhân công theo giờ làm thực tế, ra lợi nhuận, xuất Excel gửi sếp. Xử lý hoàn toàn trong trình duyệt, không gửi file lên đâu cả.

Bước 1 — Lấy Timesheet

Upload file Detail Timesheet Report (.xlsx, sheet "Query Report") hoặc lấy trực tiếp từ ERP theo dự án + khoảng ngày.
🕒
Detail Timesheet Report (từ ERP)

.xlsx — sheet "Query Report"

Xóa ✕

Bước 2 — Nạp file PAKD dự án

File PAKD phải có sheet Monitor (bảng đơn giá theo cấp bậc) và 1 sheet chứa chữ "PAKD" (bảng Doanh thu/Chi phí/Lợi nhuận).
📊
File PAKD dự án

.xlsx — ví dụ MerapLion_PL08_PAKD.xlsx

Xóa ✕

Bước 3 — Xác nhận cấp bậc chưa nhận diện được

Các chức danh dưới đây không khớp tiền tố chuẩn (Fresher/Junior/Middle/Senior) — chọn đúng cấp bậc đơn giá trước khi tính.
