Dùng đúng key hệ thống mặc định giống hệt file EXE gốc — không cần nhập key.
Thuật toán: AES-256-CBC, PKCS7 padding, Key + IV suy ra từ key hệ thống qua PBKDF2 (HMAC-SHA1, 1000 vòng lặp), salt = chính key hệ thống, kết quả mã hóa dạng Base64 — port lại chính xác từ HQ.eSkyFramework.Encryption (đã đối chiếu kết quả khớp 100% với file EXE gốc).
