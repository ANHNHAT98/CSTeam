🧠 Thư viện Prompt & Skill

Nơi team lưu và chia sẻ prompt AI, skill Claude và hướng dẫn dự án (CLAUDE.md). Lấy về dùng ngay, hoặc bấm “Nhân bản” để sao chép rồi chỉnh cho đúng yêu cầu riêng (bản gốc giữ nguyên). Dùng chung cho cả team theo tài khoản đăng nhập.

Cách dùng từng loại
💬 Prompt — bấm Dùng, điền các ô biến (vd {{ma_ticket}}), bấm Copy prompt rồi dán vào Claude / ChatGPT. Khi tạo prompt, viết biến dạng {{ten_bien}}.
🧩 Skill — bấm Tải .zip. Claude.ai: Settings → Capabilities → Skills → Upload skill, chọn file .zip. Claude Code: giải nén vào thư mục .claude/skills/ của dự án (cả team dùng chung qua git) hoặc ~/.claude/skills/ (chỉ máy bạn).
📘 Hướng dẫn dự án — bấm Tải file (mặc định CLAUDE.md), đặt ở thư mục gốc dự án để Claude Code tự đọc; với Claude.ai thì dán vào Project → Instructions.
