🛟 Backup Prod trước khi Deploy

Nhận file ZIP tổng hợp đã gom (tải từ tool "Gom Build Release") và thư mục Prod hiện tại — so sánh theo đường dẫn, file nào trùng (sắp bị ghi đè khi deploy) sẽ được lấy bản đang chạy trên Prod, đóng gói lại thành 1 ZIP backup riêng.

Công cụ này tách riêng — vì thư mục Prod thường cần tài khoản/quyền truy cập server công ty, khác với người/máy thực hiện bước gom build.

1. File ZIP tổng hợp đã gom (output của tool Gom Build Release)

Chưa có dữ liệu.

2. Thư mục Prod hiện tại

📂 Cách A — Chọn riêng từng thư mục con (khuyên dùng — nhẹ, nhanh, không bị treo như chọn nguyên thư mục gốc)
📦 Thư mục bin
🖼️ Thư mục Views
📜 Thư mục Scripts
📂 Cách B — Chọn nguyên thư mục gốc (App) — chỉ dùng nếu thư mục không quá nhiều file
📁 Cách C — Upload 1 file ZIP của thư mục Prod
⚡ Cách D — Chọn nhanh từng file cụ thể (Ctrl+click nhiều file), không quét cả thư mục — nhẹ nhất

Chỉ dùng cho bin và Scripts (tên file đã có tên module riêng, ví dụ AR20600.dll). Không dùng cho Views vì nhiều module dùng chung tên file như Index.cshtml, Body.cshtml — dễ nhận nhầm. Với Views, dùng Cách A, chỉ cần vào đúng các thư mục con nhỏ theo danh sách ở khung "Cần tìm trên Prod" phía trên.

Chưa có dữ liệu.

3. Kết quả so sánh

4. Tải Backup

1 file ZIP chứa đúng những file đang chạy trên Prod mà bộ release sắp ghi đè — lỡ deploy lỗi thì copy ngược lại là khôi phục được.

Sẵn sàng.
