Tỷ lệ đạt SLA theo Nhóm Priority (KPI 70/30) — theo dự án
Nhóm 1 = Critical & Urgent (P1, P2), chiếm tối đa 70% điểm KPI — % Actual < 95% thì Actual 1 (áp dụng) = 0, ngược lại Actual 1 (áp dụng) = % Actual × 70%.
Nhóm 2 = High, Medium, Low… (P3, P4, P5), chiếm tối đa 30% điểm KPI — % Actual < 80% thì Actual 2 (áp dụng) = 0, ngược lại Actual 2 (áp dụng) = % Actual × 30%.
Điểm KPI = Actual 1 (áp dụng) + Actual 2 (áp dụng). "Đạt điều kiện" = Điểm KPI ≥ 90% → Đạt SLA, ngược lại Không đạt SLA.
