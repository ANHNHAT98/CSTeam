📦 Gom Build Release (nhiều lần Rls)

Gom nhiều lần release (Rls lần 01, 02...) của dev — mỗi lần chỉ chứa phần thay đổi. Tool tự lấy bản file mới nhất theo từng đường dẫn (lần sau override lần trước, file nào lần sau không đổi thì giữ nguyên), rồi đóng gói lại thành 1 ZIP theo bin/, Views/, Scripts/, SQL/.

Công cụ này tách riêng, không liên quan tới tool Deploy/Backup SQL PROC.

1. Đưa dữ liệu vào

📁 Cách A — Upload 1 file ZIP tổng (chứa các thư mục "Rls lần 01", "Rls lần 02"... mỗi thư mục có các file zip theo module)
📂 Cách B — Chọn trực tiếp thư mục gốc trên máy (không cần zip trước)
Chưa có dữ liệu.

2. Nguồn từng file (theo lần Rls mới nhất)

Dòng có nền cam = file đã được lần Rls sau ghi đè (bấm để xem lịch sử các lần).

3. Danh sách Store (PROC) phát hiện được

4. Tải kết quả

1 file ZIP duy nhất: bin/, Views/, Scripts/ theo đúng cấu trúc gốc (bản mới nhất mỗi module) + SQL/<Module>/... (từng file gốc) + 1 file SQL đã gộp sẵn theo thứ tự 1xxx → 2xxx → 3xxx + danh sách Store.

Sẵn sàng.
